Power BI

Levar os números para o Power BI.

Duas formas. A rápida é baixar as planilhas (CSV) e abrir no Power BI ou no Excel. A definitiva é ligar o Power BI direto no banco: ele atualiza sozinho.

  1. Planilhas Baixe o ZIP, descompacte numa pasta e, no Power BI, use Obter dados → Pasta. Vêm quatro tabelas: resumo, compras, itens e porções por hora. ↓ Este evento ↓ Todos os eventos
  2. Direto no banco Obter dados → Banco de dados PostgreSQL, servidor localhost, banco sopao, usuário powerbi, modo Importação. Use as views vw_resumo_evento, vw_itens, vw_conferencia_notas e vw_distribuicao.
